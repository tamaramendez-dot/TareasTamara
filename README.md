## 🎯 Objetivo del repositorio

El objetivo principal de este repositorio es centralizar y organizar todos los ejercicios prácticos realizados durante la materia, de manera que puedan consultarse y evaluarse fácilmente. Cada proyecto permite poner en práctica los conceptos aprendidos en clase, mejorar habilidades en programación, desarrollo web y gestión de repositorios en GitHub.  

Este repositorio sirve como evidencia tangible del progreso académico y del dominio de los temas abordados, permitiendo llevar un control más claro de los logros y áreas de oportunidad. Todos los ejercicios están organizados en carpetas independientes para mantener un orden lógico y coherente.  

Además, se busca fomentar buenas prácticas en el manejo de archivos, nomenclaturas y versiones de proyectos, asegurando que cada ejercicio pueda revisarse y ejecutarse sin dificultades. Este repositorio no solo centraliza los archivos, sino que también documenta brevemente cada proyecto mediante nombres de carpetas descriptivos y comentarios en los códigos, lo que facilita su comprensión y análisis.

---

## 🗂 Organización del repositorio

El repositorio está organizado de la siguiente manera:

- Carpeta raíz: `VSC`  
- Dentro de `VSC` hay subcarpetas para cada ejercicio:
  - `p5 dibujo`: ejercicios de animación y dibujo con p5.js  
  - `JSON dice que`: ejercicios de manipulación de JSON y generación de instrucciones  
  

Cada subcarpeta contiene todos los archivos necesarios (`.html`, `.css`, `.js`, `.json`) para ejecutar los proyectos de forma independiente. Esta estructura permite:

- Mantener los proyectos diferenciados.  
- Acceder rápidamente a cualquier ejercicio.  
- Mantener consistencia en nombres de archivos y carpetas.  
- Facilitar la revisión por parte del profesor.  

La jerarquía clara asegura que todos los archivos estén organizados, accesibles y listos para su evaluación.

## ✨ Experiencia personal de crear y gestionar el repositorio

Crear y gestionar este repositorio ha sido una experiencia muy enriquecedora. Me permitió aplicar conocimientos teóricos en un contexto práctico y entender la importancia de mantener un orden lógico en proyectos digitales.  

Aprendí a utilizar Git y GitHub: desde inicializar un repositorio, agregar y commitear cambios, configurar la rama principal, hasta subir proyectos de manera segura usando tokens de acceso. Además, entendí cómo resolver conflictos con submódulos y gestionar carpetas dentro del repositorio, asegurando que todos los ejercicios estén organizados y accesibles.  

Documentar el repositorio mediante un README completo me enseñó a comunicar claramente el objetivo, la organización y la experiencia personal en cada proyecto. En general, esta práctica no solo reforzó mis habilidades técnicas, sino también mi disciplina para la gestión de proyectos digitales, la documentación y la presentación profesional de mi trabajo.
